# Poznáváme přírodu

Kvíz a kartičky s fotkami 478 druhů (stromy, květiny, houby, ptáci, savci, hmyz, obojživelníci a plazi).
Fotky: Wikimedia Commons, autor a licence u každé fotky (data.js); stažené a zmenšené do img/ (WebP, 800 px) skriptem `tools/localize.py`. Data: `tools/species.txt` → `python3 tools/build2.py` (species2.txt; české názvy z cs.wikipedia přes Wikidata), ruční výběr fotek `tools/cands.py`.
